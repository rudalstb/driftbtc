개인정보처리방침

마지막 수정 2026년 11월 18일
요약: 회원 가입이 없고, 이름·이메일·IP 같은 개인정보를 저장하지 않습니다. 방문자 수는 익명 번호로만 셉니다. 거래 내역 파일은 브라우저 안에서만 처리되고 서버로 전송되지 않습니다.

1. 수집하는 정보

  • 익명 방문 집계 — 브라우저가 스스로 만든 임의의 번호(개인을 식별할 수 없음)로 순 방문자 수·조회수·접속 중 인원을 셉니다. IP 주소, 기기 정보, 위치는 저장하지 않습니다.
  • 화면 이용 집계 — 어떤 영역(예: 계산기, 신호등)이 얼마나 쓰이는지 영역 이름과 횟수만 셉니다. 입력한 값은 포함되지 않습니다.
  • 투표·한마디·주간 게임 — 롱/숏 투표, 직접 쓴 한마디, 주간 범위 맞히기에 고른 범위는 위의 익명 번호와 함께 서버(Vercel)에 저장되어 결과·순위 집계에 쓰입니다. 한마디에는 개인정보를 적지 말아 주세요. 한마디는 다른 방문자에게 공개됩니다.
  • 급변 푸시 알림 — 직접 켠 경우에만, 브라우저가 만든 푸시 주소와 암호화 키를 서버(Vercel)에 저장해 알림을 보내는 데만 씁니다. 이름·연락처는 받지 않으며, 끄면 바로 지워지고 브라우저가 구독을 해지해도 자동으로 지워집니다.

2. 수집하지 않는 정보

  • "내 매매 해부"에 올리는 거래 내역 파일은 이용자의 브라우저 안에서만 읽고 분석하며, 서버로 전송하거나 저장하지 않습니다.
  • 리스크 계산기에 입력한 잔고 등은 이용자 브라우저의 저장소(localStorage)에만 남아 다음 방문 때 편의를 위해 쓰이며, 운영자는 볼 수 없습니다. 브라우저 데이터 삭제로 지울 수 있습니다.

3. 쿠키와 브라우저 저장소

로그인 쿠키는 사용하지 않습니다. 통화 선택(원화/달러), 계산기 입력값, 접은 영역, 가격 알림 목록, 투표·게임 참여 표시 같은 화면 설정을 브라우저 저장소(localStorage)에 보관합니다.

홈 화면에 추가(앱 설치)와 끊긴 연결에서도 열리도록 서비스 워커가 페이지·스크립트·최근 예측 데이터를 브라우저 캐시에 저장합니다. 이 캐시는 기기 안에만 있고 운영자에게 전송되지 않으며, 브라우저의 사이트 데이터 삭제로 지울 수 있습니다.

4. 광고

사이트에는 주식회사 카카오의 광고 서비스인 카카오 애드핏 광고가 나옵니다. 매매 가이드 글의 중간과 끝, 가이드 목록과 소개 페이지 끝, 메인 화면 맨 아래에 한 칸씩이며, 차트·예측·신호등 사이에는 넣지 않습니다. 앞으로 Google AdSense 같은 다른 제3자 광고가 게재될 수도 있습니다.

  • 광고 제공자는 광고를 보여 주고 횟수를 세고 관심사에 맞는 광고를 고르기 위해 자체 쿠키나 기기 정보를 사용할 수 있으며, 이는 각 제공자의 방침(카카오 개인정보 처리방침, Google 광고 정책)을 따릅니다. 브라우저 설정에서 쿠키를 막거나 지울 수 있습니다.
  • 광고가 실제로 채워졌는지 알기 위해, 광고 칸을 만들 때와 광고가 채워졌을 때 '앱 이름·광고 자리·PC인지 휴대폰인지'만 rudals.app 익명 집계 서버에 날짜별 횟수로 셉니다. 계산기 입력값이나 거래 내역은 광고에 넘기지 않습니다.
  • 광고 내용은 운영자가 보증하지 않으며, 투자 상품 광고도 투자 권유가 아닙니다.

5. 외부 서비스

시세·시장 데이터는 바이낸스·업비트·야후 파이낸스 등 공개 API 에서 받아옵니다. 실시간 시세·1분봉·차트·강제 청산 흐름은 이용자 브라우저가 바이낸스에 직접 요청하므로, 일반적인 웹 접속처럼 해당 서비스가 접속 IP 를 볼 수 있습니다. 이때 보내는 것은 공개 시세 요청뿐이며 이용자가 입력한 값은 포함되지 않습니다. 사이트는 GitHub Pages 와 Vercel 에서 호스팅됩니다.

6. 보관과 파기

익명 집계값은 통계 목적으로 보관하며, 날짜별 세부 집계는 40일 뒤 자동 삭제됩니다.

7. 문의

개인정보 관련 문의는 이메일 로 보내 주세요. 이 방침은 변경될 수 있으며, 변경 시 이 페이지에 수정일을 표시합니다.
