개인정보처리방침

마지막 수정 2026년 10월 19일
요약: 회원 가입이 없고, 이름·이메일·IP 같은 개인정보를 저장하지 않습니다. 방문자 수는 익명 번호로만 셉니다. 거래 내역 파일은 브라우저 안에서만 처리되고 서버로 전송되지 않습니다.

1. 수집하는 정보

  • 익명 방문 집계 — 브라우저가 스스로 만든 임의의 번호(개인을 식별할 수 없음)로 순 방문자 수·조회수·접속 중 인원을 셉니다. IP 주소, 기기 정보, 위치는 저장하지 않습니다.
  • 화면 이용 집계 — 어떤 영역(예: 계산기, 신호등)이 얼마나 쓰이는지 영역 이름과 횟수만 셉니다. 입력한 값은 포함되지 않습니다.

2. 수집하지 않는 정보

  • "내 매매 해부"에 올리는 거래 내역 파일은 이용자의 브라우저 안에서만 읽고 분석하며, 서버로 전송하거나 저장하지 않습니다.
  • 리스크 계산기에 입력한 잔고 등은 이용자 브라우저의 저장소(localStorage)에만 남아 다음 방문 때 편의를 위해 쓰이며, 운영자는 볼 수 없습니다. 브라우저 데이터 삭제로 지울 수 있습니다.

3. 쿠키와 브라우저 저장소

로그인 쿠키는 사용하지 않습니다. 통화 선택(원화/달러), 계산기 입력값, 접은 영역 같은 화면 설정을 브라우저 저장소에 보관합니다.

4. 광고

사이트에 제3자 광고(예: Google AdSense)가 게재될 수 있습니다. 광고 제공자는 이용자의 관심사에 맞는 광고를 보여 주기 위해 자체 쿠키를 사용할 수 있으며, 이는 해당 제공자의 개인정보처리방침을 따릅니다. 맞춤 광고는 Google 광고 설정에서 해제할 수 있습니다.

5. 외부 서비스

시세·시장 데이터는 바이낸스·업비트·야후 파이낸스 등 공개 API 에서 받아오며, 이 과정에서 이용자의 정보가 해당 서비스로 전달되지는 않습니다(서버가 대신 요청하거나 공개 데이터만 요청). 사이트는 GitHub Pages 와 Vercel 에서 호스팅됩니다.

6. 보관과 파기

익명 집계값은 통계 목적으로 보관하며, 날짜별 세부 집계는 40일 뒤 자동 삭제됩니다.

7. 문의

개인정보 관련 문의는 GitHub 이슈로 남겨 주세요. 이 방침은 변경될 수 있으며, 변경 시 이 페이지에 수정일을 표시합니다.
